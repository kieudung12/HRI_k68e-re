# Configuration

Bài này dùng trực tiếp các cấu hình Humble chính thức của `turtlebot4_navigation`:

- `slam.yaml` cho SLAM Toolbox;
- `localization.yaml` cho AMCL/localization;
- `nav2.yaml` cho Nav2.

Không tạo bản sao cấu hình khi chưa có nhu cầu thay đổi tham số. Các lệnh chạy và đường dẫn map nằm trong README ở thư mục gốc.
